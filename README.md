# About
**TimeSkip** is a simple timeline app designed to show that game engines can be used to build practical, usable software rather than just games.<br><br>
The main purpose of TimeSkip is to create interactive, customizable timelines containing various events. Events can be added, edited, and rearranged as needed, making it easy to build and modify a timeline on the go.
Timelines can be useful in a variety of situations, such as:
* **Analyzing events** that contributed to a particular outcome
* **Visualizing important milestones** in a company's history
* **Presenting the development of a project** over time
* **Documenting significant events** in an individual's life
* **Understanding relationships between events** and their consequences

**TimeSkip** aims to provide a simple and free way to organize events chronologically and make complex situations easier to understand.
# Future Development
As of now, **TimeSkip** is still in the early stages of development and has a limited set of features. Some of the features planned for future development include:
* A marker, representing the current time on the timeline
* The option to add timespans besides the singular events
* More event customization options like event resizing and changing text color
* The ability to save and export the time data in a convenient format
